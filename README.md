# 🥋 Site de Blog Artes Marciais

Site de blog de artes marciais, desenvolvido com HTML, CSS, JavaScript e jQuery, com filtros dinâmicos de conteúdo e interações visuais.

---

## 🎯 Funcionalidades

- 🧭 Barra de navegação com efeito de sombra ao rolar a página
- 🗂️ Filtro de postagens por categoria
- ✨ Animações suaves ao exibir ou ocultar posts
- 🖱️ Destaque visual do filtro ativo
- 📱 Layout responsivo
- ⚡ Interações dinâmicas com JavaScript e jQuery

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript**
- **jQuery**
